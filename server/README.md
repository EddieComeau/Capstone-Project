# 🏈 NFL Cards & Betting Companion

An interactive NFL dashboard combining real-time plays, team/player insights, and betting odds — all with sprite/lottie field views and avatar-rich UI.

---

## ⚙️ Quick Start

```bash
# Clone the repo
git clone https://github.com/EddieComeau/Capstone-Project.git
cd Capstone-Project

# Backend
cd server
cp .env.example .env  # or create manually
npm install
npm start

# Frontend
cd ../frontend
npm install
npm run dev
